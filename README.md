

## About

**Campers (TravelTrucks)** is a small web app for browsing camper vans.  
It includes a landing page and a catalog page where users can search and filter available campers.

## Features

- **Landing page** with a short promo message and a CTA button leading to the catalog.
- **Catalog page** for browsing campers.
- **Filtering** by:
  - **Location**
  - **Vehicle equipment** (e.g., AC, kitchen, bathroom, refrigerator, etc.)
  - **Vehicle type** (Van / Fully Integrated / Alcove)
- Responsive, clean UI and client-side navigation.

## Tech Stack

- **Next.js** (App Router structure: `/app`)
- **TypeScript**
- Component-based UI structure (`/components`)
- Deployed on **Vercel**
